
# Confluo

A collaborative infinite canvas application.

## Current milestone: Slice A

- Create and save boards
- Fabric.js canvas rendering
- Rectangles, circles, and text
- Object selection and transformations
- Pan and zoom
- Local persistence

## Development

```bash
cd apps/web
npm install
npm run dev
```

## Build verification

```bash
npm run build
```

## Planned milestones

- Slice B: Real-time collaboration using Yjs and WebSockets
- Slice C: Offline editing and recovery using IndexedDB
- Slice D: Undo/redo, revision snapshots, and branching
- Slice E: Spatial presence and proximity-based audio
